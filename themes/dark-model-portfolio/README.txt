DARK MODEL PORTFOLIO — WORDPRESS THEME
====================================

INSTALLATION
1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Upload the ZIP file supplied with this project.
3. Activate “Dark Model Portfolio”.
4. Go to Model Portfolio > Portfolio Settings to edit all major homepage text, images, links and profile details.
5. Go to Model Portfolio > Add New to add gallery photos.
6. Set a Featured Image for each portfolio item and assign one or more Portfolio Categories.
7. In the Portfolio Display box, set Display Order and optionally enable “Show in Selected Work”.
8. Optional: create a menu in Appearance > Menus and assign it to Primary Navigation. If no menu is assigned, the theme automatically uses Home, Portfolio, Profile and Contact anchor links.
9. Optional: add a logo under Appearance > Customize > Site Identity (or the equivalent Site Logo control provided by WordPress).

HOW THE HOMEPAGE WORKS
- Hero, marquee, profile, statement, contact and footer text are editable from Portfolio Settings.
- Hero and profile images can be chosen from the WordPress Media Library.
- Selected Work automatically uses up to 3 portfolio items marked “Show in Selected Work”.
- Main gallery automatically lists all published Portfolio items.
- Portfolio filter buttons are generated from Portfolio Categories.
- If no Portfolio items have been added yet, the original supplied photos are shown as starter/fallback content, so the design works immediately after activation.

NO REQUIRED PLUGINS
This theme uses native WordPress APIs. ACF, Elementor and other page builders are not required.

RECOMMENDED IMAGE WORKFLOW
Use portrait WebP/JPEG images around 1600–2400px on the long edge and compress them before upload for better performance.
